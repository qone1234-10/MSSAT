# README

## Required Dependencies

Before running the code, please download the required external packages and place them in the corresponding folders.

### MATLAB Dependencies

Download the following packages into the `MATLAB/` folder:

1. **AJIVE**  
   - Paper: *Angle-based Joint and Individual Variation Explained (AJIVE)*  
   - GitHub: https://github.com/idc9/ajive

2. **DIVAS**  
   - Paper: *DIVAS*  
   - GitHub: https://github.com/jbprothero/Data-Integration-Via-Analysis-of-Subspaces

3. **CVX** (Convex Optimization Toolbox)  
   - Official website: https://cvxr.com/cvx/

---

### R Dependencies

Download the following packages into the `R/` folder:

1. **PPD**  
   - Authors: Gaynanova et al.  
   - Supplementary code and implementation provided in:
     Gaynanova et al., "A spectral framework for multi-view subspace learning using the product of projections"
     
2. **BIDIFAC+**  
   - Authors: Lock et al.  
   - GitHub: https://github.com/lockEF/bidifac
